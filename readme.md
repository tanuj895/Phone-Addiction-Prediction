# Phone Addiction Prediction

A Machine Learning project that predicts smartphone addiction based on usage and lifestyle data.

## Features

* Data preprocessing and cleaning
* One-Hot Encoding and feature scaling
* Logistic Regression, Decision Tree, and Random Forest
* Model evaluation using accuracy, classification report, and confusion matrix
* Interactive Streamlit web application

## Model Accuracy

| Model               | Accuracy |
| ------------------- | -------: |
| Logistic Regression |   89.33% |
| Decision Tree       |   93.00% |
| Random Forest       |   94.20% |

## Technologies

* Python
* Pandas
* Scikit-learn
* Joblib
* Streamlit

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Prediction

The application takes smartphone usage and lifestyle details as input and predicts:

**Addicted / Not Addicted**
